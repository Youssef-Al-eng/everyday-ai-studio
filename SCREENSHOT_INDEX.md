# Screenshot index and review gallery

Screenshots are regenerated from the actual local browser app using Playwright-controlled Chrome. The final validation checked 63 non-empty PNG files (all valid). The gallery is available at `/#/gallery` after `npm start`. Every **Result** screenshot shows a real, labeled live response — `GROQ RESPONSE · openai/gpt-oss-20b` received from the Groq API during the verified 2026-10-26 run (see `inventory/live-groq-verification.json` and `inventory/browser-verification.json`). Desktop and mobile captures show the helper workspace before running. Sample (offline demo) results remain available in the app and are always labeled `SAMPLE RESULT · OFFLINE`.

Home and catalog: `outputs/portfolio-home.png`, `outputs/agent-directory.png`. Seven-family review gallery: `outputs/design-gallery.png`.
